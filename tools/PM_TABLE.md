# pm_table 偏移地图 (Strix Point, 表版本 0x5D0009)

自研 SMU 通道读出的遥测表(8KB float32 数组)的逆向记录。
方法论:`tools/pm_sweep.py`(逐核钉载采样,空闲/全核基线)→ `tools/pm_analyze.py`
(全偏移对基准真值做皮尔逊相关 + 单核选择性检验 + 常量聚类)。

基准真值:k10temp Tctl、RAPL Package 功率、amdgpu PPT(SMU 视角整机功率)、
每核 MSR 功率(rustinfo dump)、cpufreq 每线程频率。快照 13 个(空闲×2、逐核×10、全核×1)。

## v1 已确认字段

| 偏移 | 含义 | 依据 | 置信 |
|---|---|---|---|
| `0x0990` | **Tctl (°C)** | 与 k10temp 相关系数 **1.000**,范围 49.3~68.6 | 高 |
| `0x0994` | 峰值温度(热点/最热核?) | r=0.996,极值比 Tctl 高 ~4°C | 中 |
| `0x0044` / `0x0A3C` | 复合体/CCD 温度(互相镜像) | r≈0.99 | 中 |
| `0x000C` / `0x00D0` | **Socket 功率 (W)**(SMU PPT 实际值) | 与 amdgpu PPT 逐点吻合(18.3↔18.3) | 高 |
| `0x0004` | 功率(口径略窄于 socket,疑似 CPU+SoC) | r=0.997,与 PPT 差 ~0.3-1W | 中 |
| `0x0034` / `0x02C0` | 平滑滤波功率(慢速环) | 幅度略低、更平 | 低 |
| `0x02C4` / `0x00A4` | CPU 复合体功率(不含 SoC/GPU) | 幅度约为 socket 的 60-80% | 低 |
| `0x008C` | 功率限额 ~15W(本机 STAPM/PPT 档) | 全程恒定 15.0,量级吻合 | 中 |
| `0x0ACC` | PPT 利用率 (%) | 钉满载时 100%,单核 10-35% | 中 |
| `0x0988` | 未知功率(恒高于 socket ~30%,疑似峰值/目标) | r=0.98 | 低 |
| `0x017C`/`0x0180`/`0x0078` | ~1.35 且与温度反相关 — 疑似裕量(margin) | r=-0.997 | 低 |

## 常量区(已破译)

- `0x0254`-`0x0718` 一带:**DPM 时钟表**(与 pp_dpm_* 文件吻合):
  937.5/800/400 = mclk 三档,981.33/974.77/960/883.2/800/600/300… = 各时钟域档位
- `95.00`(0x40-0x58 区)与 `92.00`:温度墙
- `5.05`/`3.30` 重复区(0x0D4-0x118):疑似最小功率/频档地板

## 待逆向

- 每核字段(时钟/功率/VID):v1 单轮钉载选择性不足(热噪声污染),需每核 3 次重复 +
  全核基线交叉,按"该核钉载且唯一响应"判定
- 电流 (A)、fclk/uclk 实时值、GPU 子域功率
- `0x1A00`+ 区域存在 ±500~900 的非物理 float(疑似非遥测数据/打包字段)

## 复现

```bash
sudo python3 tools/pm_sweep.py     # 约 90s, 输出 /tmp/pm_sweep/
python3 tools/pm_analyze.py        # 相关性报告 + /tmp/pm_map.json
```
